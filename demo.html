Engineering Rigor

Technical Architecture & Rationale

Core engineering paradigms implemented throughout the full-stack codebase.

Interval Overlap Collision Detection

Double booking is prevented on the database level via temporal collision checking: newStart < existingEnd && newEnd > existingStart evaluated inside appointmentService.js.

JWT & Middleware RBAC Guards

Decoupled authorization: authenticateUser verifies bearer JWT signatures, while authorizeRoles(...) enforces fine-grained permission arrays per API endpoint.

Layered Separation of Concerns

Clean architectural tiering: Routes -> Middleware -> Controllers -> Services -> Mongoose Models. Business rules remain completely isolated from transport protocols.
